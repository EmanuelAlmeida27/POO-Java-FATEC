# 📚 POO — Programação Orientada a Objetos em Java

Repositório com os projetos e exercícios desenvolvidos durante a disciplina de **Programação Orientada a Objetos** na faculdade, usando **Java** e **NetBeans IDE**.

## 🗂️ Organização

Os projetos estão organizados por ordem de aula:

| Pasta | Data | Conteúdo |
|-------|------|----------|
| `Aula_01 - Introducao e Primeiros Exemplos` | 04/08 | Primeiros exemplos em Java |
| `Aula_02 - Atributos e Metodos` | 11/08 | Atributos, métodos e comportamento de objetos |
| `Aula_03 - Classes e Objetos` | 17/08 | Criação de classes e instâncias |
| `Aula_04 - Encapsulamento` | 18/08 | Encapsulamento com getters e setters |
| `Aula_05 - Encapsulamento Avancado` | 24/08 | Encapsulamento aplicado (Círculo e Retângulo) |
| `Aula_06 - 25_08` | 25/08 | — |
| `Aula_07 - Heranca sem Polimorfismo` | 31/08 | Introdução à herança |
| `Aula_08 - Heranca sem Polimorfismo - Exercicios` | 01/09 | Exercícios de herança |
| `Aula_09 - Heranca com Polimorfismo` | 08/09 | Polimorfismo com Funcionário/Horista/Mensalista |
| `Aula_10 - Heranca com Polimorfismo - Avancado` | 14/09 | Polimorfismo avançado com Funcionário Comissionado |
| `Aula_11 - ArrayList e this` | 19/10 | Coleções com ArrayList e uso do `this` |
| `Aula_12 - Interface Grafica (GUI)` | 26/10 | Introdução ao Swing/GUI |
| `Aula_13 - Interface Grafica (GUI) - Avancado` | 27/10 | GUI com eventos e múltiplos componentes |

## 🧠 Tópicos Abordados

- Classes, objetos e encapsulamento
- Herança e especialização
- Polimorfismo
- Coleções (`ArrayList`) e referência `this`
- Interfaces gráficas (GUI com Swing)
- Boas práticas de POO em Java

## 🛠️ Tecnologias

- **Linguagem:** Java
- **IDE:** Apache NetBeans
- **Paradigma:** Orientado a Objetos
